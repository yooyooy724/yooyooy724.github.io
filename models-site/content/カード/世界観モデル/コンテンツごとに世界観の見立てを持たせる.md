**原則**: 各コンテンツに世界の中での位置づけ（見立て）を与え、名前・画面・絵・音をその見立てに沿わせる。ある見立ては他のコンテンツに持ち込まない。

## なぜ

- yooyo の方針: コンテンツごとに世界観を持たせる。Challenge も同じに考える（ADR-0101）
- Cave の Strutum と敵の強さを結ぶと世界観をつなげられる（ADR-0022）
- yooyo の指示: 「Area4 やボスという単語を世界観に基づき大きく変更します」（ADR-0349）
- yooyo の指摘: ウィンドウスタイルはオートメーションに限った話で、他のレリックに適用してはいけない（ADR-0272）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| Challenge は祠を介して発動する試練とし、入口のアイコンは祠にする | Idle MInertia | ADR-0101 |
| Battle はタワーディフェンス型にし、Cave の Strutum と敵の強さを結ぶ | Idle MInertia | ADR-0022 |
| Relic の3タブは3人の仲間（エンジニア・鍛冶職人・現場の人）に当てる | Idle MInertia | ADR-0065 |
| Automation はプログラミング風のテーマにし、各カテゴリを PC の画面に見立てる | Idle MInertia | ADR-0265 |
| OS ウィンドウの見た目は Relic の Automation だけに使い、他の Relic には適用しない | Idle MInertia | ADR-0272 |
| Relic ポップアップの背景は、そのタブを示すアイコンを並べた模様にする | Idle MInertia | ADR-0284 |
| ザ・ディープは真っ白な水面の世界にし、部隊・ブロック・？？？を映して揺らす。音は反響を掛けて低くする | Idle MInertia | ADR-0363 |
| ？？？は水面にだけ本当の姿が映る。殻を壊した瞬間は揺れが止まる | Idle MInertia | ADR-0363 |

## 境界

- Bazaar を日本の飲料の自動販売機にした（ADR-0271）が、「正直もとにもどしたい」で露店の見た目に戻した（ADR-0357）
- ザ・ディープで部隊の時間を 1/3 に遅くする演出（ADR-0363）は「遅すぎる」でいったん普通の速さに戻した。仕組みは残す（ADR-0362）
- 見立ての具体案（OS ウィンドウ / ブラウン管 / エディタタブ など）の選び方は都度決めている（ADR-0265）
