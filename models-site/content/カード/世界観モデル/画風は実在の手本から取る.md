**原則**: 画風と配色は、誰でも思い浮かぶ実在の手本から取る。候補は文章で比べず、描いた実物を見て選ぶ。

## なぜ

- AI が調整した浮世絵の配色に納得できず、手調整を重ねるたびに「浮世絵感がなくなる」状態が続いた（ADR-0138）
- 自分好みの調整より実物の配色のほうが画風として安定する（ADR-0138）
- 意味が伝わらない案（「LigeGame」案）を出されたため、想起しやすい画風を指定した（ADR-0118）
- yooyo の発言: 「実際に模様を見たい」「デザインの判断に必要なだけなので Unity である必要はない」（ADR-0127）
- yooyo の発言: 「全然自動販売機感がないので、まずは自動販売機の画像を入手することや、デザインを Unity 関係なく計画するところから始めましょう」（ADR-0274）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 新しい見た目は既存エフェクトの流用ではなく、「ボダラン風」のように想起しやすい画風で作る | Idle Sphere | ADR-0118 |
| 浮世絵の配色は時刻ごとに手本の作品を決めて抽出する（昼＝北斎「神奈川沖浪裏」、夕＝広重「亀戸梅屋舗」、夜＝広重「猿わか町よるの景」） | Idle Sphere | ADR-0138 |
| 昼・夕・夜の配色は滑らかに循環させる | Idle Sphere | ADR-0138 |
| 絵作りの指示は画面の領域（地・粒の面・粒の縁・群れ）に名前を付けてから行う | Idle Sphere | ADR-0127 |
| 模様は文章でなく描いた実物を見て選ぶ。判断に必要なだけなら Unity で描かなくてよい | Idle Sphere | ADR-0127 |
| UI の見た目を作り直すときは「参考画像を集める → Unity と無関係にデザインする → Unity で差をなくす」の順で進める | Idle MInertia | ADR-0274 |
| UI デザインを考えるときは、その都度 Pinterest（と他の AI）で参考を探してから案を出す | Idle MInertia | ADR-0265 |
| 元絵のない新しいキャラ絵は、元絵のパレットと画風（黒い太線・平塗り・角ばった形）に合わせて描く | 共通ライブラリ | ADR-0260 |

## 境界

- Shader Graph は GUI 前提で AI が直接書けないため、新しい画風はフルスクリーンエフェクトで作る（ADR-0118）
- Idle MInertia の画風そのものを決めた ADR はない

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0118 | 2026-08-12 | 新しい見た目 DLC は既存の流用でなく、誰でも思い浮かぶ画風を球面パーティクルにかけるフルスクリーンエフェクトで作る |
| ADR-0127 | 2026-08-22 | 絵作りの指示は画面の領域に名前を付けてから行い、模様は文章でなく描いた実物を見て選ぶ |
| ADR-0138 | 2026-08-31 | 浮世絵 DLC の配色は AI の調色でなく実在の浮世絵を手本にし、昼・夕・夜で滑らかに循環させる |
| ADR-0260 | 2026-10-06 | 元絵のない新しいキャラ絵は Rakugaki の塗り＋太線で手描きする |
