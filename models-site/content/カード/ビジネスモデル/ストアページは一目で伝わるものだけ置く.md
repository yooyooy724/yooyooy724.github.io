**原則**: ストアの文言は流入する重要語に絞る。画像は 1 枚のキーアートから全部を派生させ、アイコンとロゴは遠目でも読めるようにする。

## なぜ

- ore・gem で検索した人が流入するとは思えず、不要な単語に優先度を取られるより重要語に絞るべき（ユーザー、ADR-0031）
- 「アイコンは遠目でもわかりやすいようにしたい」（ユーザー、ADR-0255）
- 「背景の線の主張がつよくて字が読みにくい」（ユーザー、ADR-0257）
- 本編の完成版の見た目に揃えるため（ADR-0290）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| ストアの表記は流入しない一般語を外して重要語に絞り、旧名でも検索に引っかかるようにする。キーワードは言語ごとに調べる | Idle-MInertia | ADR-0031 |
| Steam の 9 種の素材は、p5 で描いた 1 枚のキーアートから生成する。Unity 内でストア素材を作る仕組みは廃止 | Rootflux, Idle-Factory | ADR-0235, ADR-0256 |
| ストア用のスクリーンショットは実際のゲーム画面を 1920x1080 で撮る | Idle-Factory | ADR-0256 |
| アイコンは遠目でも分かる「R」一文字にし、16px まで縮めても読めることを確かめる | Rootflux | ADR-0255 |
| 字の後ろは楕円形の暗がりで沈め、根の明るさを抑えて読みやすくする | Rootflux | ADR-0257 |
| DLC のストア画像は本編と同じ根の模様・向きで、根の色と DLC 名だけ変える。本編のページは触らず DLC 用の別ページで作る | Idle-Factory | ADR-0290 |
| 素材の作業ページはリポジトリに入れず、デスクトップのフォルダに置く | Rootflux | ADR-0249 |

## 境界

- ゲームの描画を写し取って Unity の専用シーンで作る方針（ADR-0236, ADR-0244）は、ADR-0256 で廃止
- 自然の写真に白い根とタイトルを載せる方向（ADR-0241）は試した案。根や土の写真は却下
- 手で組んだ独自レタリングと、根で字を埋めるロゴ（ADR-0237）は「変にもほどがある」「ロゴも変」と却下され、塗りの字を芯に根を添える形（ADR-0240）を経て、p5 の完成版（ADR-0256）に落ち着いた
- Rootflux のストア素材 ADR の多くは「未評価」

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0031 | 2026-03-31 | ストアの表記は流入しない一般語（ore・gem など）を外して重要語に絞り、旧名 Idle Gem でも検索に引っかかるようにする |
| ADR-0235 | 2026-10-05 | Steam のグラフィックアセットは、p5 で描いた根のキーアートと、根が伸びる独自レタリングで作る |
| ADR-0236 | 2026-10-05 | Steam のストア素材は、ゲームの描画を写し取って Rakugaki だけで組む専用シーンで作る |
| ADR-0237 | 2026-10-05 | ストアのロゴは、タイトルの書体の字の中をデザインの根が埋める形にし、素材は標準デザインで作る |
| ADR-0240 | 2026-10-05 | ストア素材のロゴは「塗りの字＋根を添える」、背景はジェネラティブの絵から選ぶ |
| ADR-0241 | 2026-10-05 | ストア素材の方向として「自然の写真＋白い根と白いタイトル」を試す（根の写真は使わない） |
| ADR-0244 | 2026-10-05 | ストア素材はゲームと同じ方法だけで作る（独自のジェネラティブは捨てる） |
| ADR-0249 | 2026-10-06 | p5 で作った Steam 素材とアイコンの作業ページは、リポジトリに入れずデスクトップのフォルダに保存する |
| ADR-0255 | 2026-10-06 | Steam のアイコンは、遠目でもわかるよう「R」一文字にし、足元から根を伸ばす |
| ADR-0256 | 2026-10-06 | Steam のストア素材は p5.js の作業ページの完成版を使い、Unity 内のストア素材の仕組みは廃止する |
| ADR-0257 | 2026-10-06 | キーアートの根は参考画像の色合い（上は緑〜黄緑、下は黄土色〜茶）にし、字の後ろは暗く沈めて読みやすくする |
| ADR-0290 | 2026-10-08 | DLC のストア画像は本編の完成版と同じ描き方で、DLC デザインの色と DLC 名だけを変えて作る |
