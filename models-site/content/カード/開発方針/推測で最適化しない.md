**原則**: 性能と容量の改善は Profiler や実測から始め、「プレイ中ずっと効き、安全なもの」から入れる。決めたこと・理由・根拠を決定ログに残す。

## なぜ

- 数値の一致や推測ではなく、計測が重さの正体を示す。フォントの重さは適用ではなく予約リストの線形探索だった（ADR-0383）
- リリース済みで、オフラインボーナスの受け取り待ちが唯一の脱出口のため、そこを壊さない（ADR-0382）
- 放置ゲームは画面を付けっぱなしにされるので、見ていないものの負荷を削る効果が大きい（ADR-0045）
- 容量の比較は推測ではなく変更前後の実測で行う（ADR-0077）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 性能改善は Profiler の計測から始め、計測データと決定ログ（決めたこと・理由・根拠）を Domain 側のフォルダに残す | Idle-MInertia | ADR-0117 |
| 「プレイ中ずっと効き、安全なもの」から入れる。一度きりで回帰リスクの大きいものは後回し | Idle-MInertia | ADR-0382 |
| 見た目に関わる部分を変えずに直せる道が見つかったら、後回しの理由は消える | Idle-MInertia | ADR-0383 |
| 毎フレーム通る処理からヒープ確保を消す（StructLinq・再利用バッファ・手書きループ） | Idle-MInertia | ADR-0032 |
| 表示していない画面の ViewModel 更新を止め、放置中は FPS を落とす | Idle-MInertia | ADR-0045 |
| 毎秒走る直列化は出力を膨らませない（Indented → None） | Idle-MInertia | ADR-0381 |
| タイル型 GPU では全画面パスを 1 本に統合し、ノイズはテクスチャに焼き込む | Idle-Sphere | ADR-0151 |
| 端末で回す画像生成は発熱・電池・対応機種の壁があるので使わず、ジェネラティブアートで描く | Rootflux | ADR-0170 |
| フレームレートは PC 60fps・モバイル 30fps。稼働中のモバイル版の電池に効く変更はしない | Idle-MInertia | ADR-0293 |
| GLES3.0 端末で動かない技術を使う重いグラフィックは PC 版だけで見せる | Idle-MInertia | ADR-0386 |
| 容量制限のある作品は毎回ビルド後の容量を実測し、重くなった処理だけ高速化する | Floppy-Generative | ADR-0075, ADR-0077 |

## 境界

- 容量優先の作品では速度よりコードの分かりやすさを優先する（ADR-0075）
- 担当の破棄で受け取りパネルが出なくなる危険がある改善は採らない（ADR-0382）

| --- | --- | --- |
| ADR-0032 | 2026-04-04 | 毎フレーム通る処理からヒープ確保を消し、そのために StructLinq を自作する |
| ADR-0045 | 2026-05-24 | 表示していない画面の ViewModel 更新を止め、5 分放置したら FPS 5 の画面に切り替える |
| ADR-0075 | 2026-07-14 | 1.44MB に収めるゲームは C++＋raylib で作り、速度よりコードの分かりやすさを優先し、データは計算で生成する |
| ADR-0077 | 2026-07-16 | 開発ログは1つの変更を1枚のカードとして残し、カードごとに Release ビルドして実行ファイルの容量を実測して書く |
| ADR-0117 | 2026-08-12 | 性能改善は Profiler の計測から始め、計測データと「決めたこと・理由・根拠」の決定ログを Domain 側のフォルダに残して進める |
| ADR-0151 | 2026-09-08 | モバイルで重い浮世絵エフェクトは、全画面パスを 1 本に統合しノイズを焼き込み、問題を起こす前フレーム合成は外す |
| ADR-0170 | 2026-09-24 | 植物の絵に StreamDiffusion などのリアルタイム画像生成は使わず、ジェネラティブアートで描く |

| ADR-0381 | 2026-10-13 | セーブの JSON は字下げ（Indented）をやめて Formatting.None で書く |
| ADR-0382 | 2026-10-13 | パフォーマンス改善は「プレイ中ずっと効き、安全なもの」から入る（オフラインボーナスの表示計算を閉じている間は止める） |
| ADR-0383 | 2026-10-13 | フォントの重さは「当て方の作り直し」ではなく「要素ごとの予約をやめる」で直す |
| ADR-0386 | 2026-10-13 | 宝石の渦グラフィックはPC（Steam）版だけで見せる |
