**原則**: AI には完成まで止まらず進めさせ、人への質問と人の手作業は積んでおいてまとめて処理する。報告は結論を先に、箇条書きと根拠付きで返させ、確認事項は毎回すべて一覧にする。

## なぜ

- 人の確認待ちで作業が完全に止まる時間を減らす（ADR-0095）
- 「私のするべきことは後でまとめてしたい」（ADR-0095、本人の発言）
- 本人は文章を読むのが苦手で、散文は読み飛ばされて伝わらない（ADR-0115）
- 「前に聞いた〜は返事待ち」とだけ書くと、何を聞かれているか分からない（ADR-0281）
- AI が一般論を少数データで後付けしようとした。「先人がいくらでもいる」（ADR-0142、本人の発言）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| Unity Editor でしか作れない作業は AI が既存の複製で土台を作り、人の作業はチェックリストに積む | Idle-MInertia | ADR-0095 |
| 画面の確認は本人、DLL のビルドは AI が担う | Idle-MInertia | ADR-0122 |
| 報告は結論を先に、1 項目 1 文の箇条書き、根拠は path:行番号。前置き禁止。短くしても主語は省かない | 全体 | ADR-0115 |
| 確認事項は毎回番号付きの一覧で全部並べ、前の報告で聞いたものも答えをもらうまで文脈なしで分かる形で載せ、各項目に推奨を添える | 全体 | ADR-0281 |
| 報告と許可待ちは VOICEVOX で読み上げる。読み上げは明示依頼時と、確認・判断・作業を求めるときに限る | 全体 | ADR-0053 |
| 施策を勧めるときは自前の少数データで結論を出さず、公開ソースや先人の集計を根拠にする。見つからなければ「根拠がない」と言う | 全体 | ADR-0142 |
| 本人の名前で出る文章の草案は解説を付けず本文だけを出し、原文の語り口を残す | 全体 | ADR-0143 |

## 境界

- 読み上げを 2 つの場合に絞った理由は不明（ADR-0053）。Codex 側は明示依頼時のみ
- AI が Editor を操作する決定（ADR-0159・ADR-0200）と「画面の確認は本人」（ADR-0122）の線引きは未決（「画面で確かめる」参照）

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0053 | 2026-06-20 | Claude Code の報告と許可待ちを VOICEVOX（里石ユカ）で読み上げる仕組みを入れる |
| ADR-0095 | 2026-07-30 | AI には完成まで止まらず進めさせ、人への質問と人の手作業は「積んで後でまとめて」処理する |
| ADR-0115 | 2026-08-11 | AI からの報告は「結論を先に、1項目1文の箇条書き、根拠は path:行番号」で返させる |
| ADR-0122 | 2026-08-18 | 大きな仕様は実装前にgrillで詰め、画面の確認はユーザー、DLLのビルドはAIが担う |
| ADR-0142 | 2026-09-02 | 施策を勧めるときは自前の少数データで結論を出さず、公開ソースや先人の集計を根拠にする |
| ADR-0143 | 2026-09-03 | 本人の名前で出る文章は原文の語り口を残して最小限だけ足し、草案は解説を付けず本文だけを出させる |
| ADR-0281 | 2026-10-07 | ユーザーへの確認事項は毎回すべて一覧にして提示する |
