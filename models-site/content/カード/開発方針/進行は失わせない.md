**原則**: 遊び手の進行は、更新・保存・クラウド同期のどこでも失わせない。既存のセーブ互換は全更新の約束にし、クラウドはロードした続きとして書き、確認なしに上書きしない。

## なぜ

- 進行の消失は遊び手にとって最悪の体験で、信頼を直接失う（ADR-0050・ADR-0087）
- リリース済みで実ユーザーがいる。「セーブデータにかかわる変更は必ずしてはいけない」（ADR-0070、本人の指示）
- 「上書きは勝手にしてはいけません。ロード後にその続きとしてセーブしていくことが基本です」（ADR-0275、本人の発言）
- 書き込み中に落ちると中身が切れて全損し、起動できなくなる（ADR-0047）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 変更のたびに旧セーブの扱いを決める（旧値は JSON 既定値で読む／読み捨てても不利が出ない／重複は先頭を残して除去） | Idle-MInertia | ADR-0062, ADR-0087 |
| 迷う破壊的変更は実装前に確認する | Idle-MInertia | ADR-0087 |
| lint の一括変換でもセーブデータに関わる変更は一切させない | Idle-MInertia | ADR-0070 |
| 保存形式に手を入れずに済む置き方を選ぶ（試練の状態はセッション内、水はブロックにしない） | Idle-MInertia | ADR-0079, ADR-0099 |
| 大きなリセットはセーブを消して再起動せず、Root ごとに消すもの・残すものを実装する | Idle-MInertia | ADR-0166 |
| 保存キーや段階を変えるときは、旧キーの値を同じ意味の段へ一度だけ移す | Idle-MInertia | ADR-0327 |
| 読み込みが空白に依存しない形式変更（Indented → None）は旧セーブをそのまま読める | Idle-MInertia | ADR-0381 |
| 価格を下げたら払いすぎた分を各プレイヤーに正確に返す | Idle-MInertia | ADR-0177 |
| ローカルのセーブは一時ファイルに書いてから原子的に置き換え、壊れていたら退避して予備から読む | Idle-MInertia | ADR-0047 |
| 暗号化への移行はリポジトリを作る時点で 1 回だけ走らせ、移行の元になる平文（local_save）は旧ビルドへ戻すために永久に残す | Idle-MInertia | ADR-0205, ADR-0207 |
| クラウドは世代トークンとプレイ時間を併記し、クラウドの方が進んでいれば自動アップロードを止める。失敗時は止める側（fail-closed）に倒す | Idle-MInertia | ADR-0050 |
| クラウドは勝手に上書きせず、別の端末やより長いデータを上書きするときは確認を取る。確認待ちで止まったらゲーム中にも確認を出す | Idle-MInertia | ADR-0275, ADR-0314 |
| 書いた端末の印は世代・保存時刻と組（uploadStamp）にし、食い違う印は信じない | Idle-MInertia | ADR-0276 |
| 手動セーブは本人の明示確認があるので衝突ガードを外し、自動セーブだけガードを残す | Idle-MInertia | ADR-0064 |
| 読めないクラウドのエントリが 1 件でもあれば、ローカルを消す前に全体を失敗にする | Idle-MInertia | ADR-0203 |
| 課金の巻き戻りは、同じ台帳（local_save と cloud_save）同士の比較で警告する | Idle-MInertia | ADR-0102 |
| 課金の復元は権利だけを戻して通貨に触れず、「失敗」と「購入なし」を画面で区別する | Idle-MInertia | ADR-0088 |
| 他人の保存先に書けないことをテストで確かめる | Idle-Sphere | ADR-0013 |
| UI 未配線の「手動バックアップ」のような改ざんの経路は持たない | Idle-MInertia | ADR-0309 |

## 境界

- テスター期間の試練の進捗は、テスト用データとして v0.9 移行で一度だけ消した。所持 Spell も消したのは起動時の自己修復と噛み合わせるため（ADR-0128）
- 大きな災害からの復旧はクラウドセーブに任せ、毎秒の全ファイル複製はしない（ADR-0047）
- セーブ確認ポップアップの色は「やめる側を青」（ADR-0304）から「クラウドの色（青緑）・文字は黒」（ADR-0316）に改めた
- 古いモバイル版向けの対処はセーブ形式の版による警告だけにする。止めると更新できない人がクラウドを使えなくなる（ADR-0314）
