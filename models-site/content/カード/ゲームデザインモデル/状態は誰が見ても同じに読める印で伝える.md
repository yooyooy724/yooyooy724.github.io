**原則**: 画面の状態は、受け取り方が人によって違う表現（色相の順、灰色、枠）ではなく、誰が見ても同じに読める印（点の数・明るさ・音程・MAX の字・透明度・タグ）で伝える。同じ事実を二重三重に示さない。

## なぜ

- 色相の順（橙＜赤など）は受け取り方が人によって違う（ADR-0175）
- 灰色は「まだ買えない」の顔で、「もう済んだ」と同じ見た目にすると区別がつかない（ADR-0220）
- 「これではほとんどの人は読まずに Load します」（ユーザー発言、ADR-0304）
- 「一番下の点滅はほんとに何か入力できる気がしちゃう」（ユーザー発言、ADR-0266）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 報酬の段は色相でなく点の数・明るさ・枠線の太さで表し、開放音は段が上がるほど音程を上げる | Idle-MInertia | ADR-0175 |
| 上限に達した行は灰色（Locked と同じ）にせず、accent 色の MAX の印で「完了」として見せる | Idle-Factory | ADR-0220 |
| 操作できない状態は枠でなく印と透明度で伝える（LOCK の印、トグルは透明度 30%、買えない行は赤いコストの数字だけ） | Idle-Factory | ADR-0224 |
| 課金で効くボタンと売り場のカードには、同じ金色の小さな「DLC」タグを付けて対応させる | Idle-MInertia | ADR-0190 |
| 警告があるセーブの確認は、警告を赤い枠の箱に太字で大きく出し、やめる側と上書きする側のボタンの色を分ける | Idle-MInertia | ADR-0304, ADR-0316 |
| 未確定の変更がある間は Apply を点滅させ、確定済みの値（Current）は最も強い反転で見せる | Idle-MInertia | ADR-0333 |
| 入力できそうに見える飾り（ターミナルの点滅カーソル）は置かない | Idle-MInertia | ADR-0266 |

## 境界

- 「やめる側を青」（ADR-0304）は同日に「クラウドの画面の色（青緑）・文字は黒」へ改めた（ADR-0316）
- 回路のデザインだけは accent を養分の色に揃え、色相の制限より指定を優先した（ADR-0223）

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0175 | 2026-09-27 | 報酬の段は色相ではなく点の数・明るさ・枠線で伝え、開放音は段が上がるほど音程を上げる |
| ADR-0190 | 2026-10-02 | DLC の印は金色の「DLC」タグにし、売り場のカードと報酬ボタンで共通にする |
| ADR-0220 | 2026-10-04 | 上限に達したアップグレード行は灰色にせず MAX の印で「完了」として見せる |
| ADR-0224 | 2026-10-04 | 操作できない状態は「枠」ではなく「印と透明度」で伝える（LOCK 印・箱なしトグル・赤い数字だけ） |
| ADR-0266 | 2026-10-07 | Automation のターミナルにはカーソルを置かない |
| ADR-0304 | 2026-10-08 | セーブの上書きを確かめるポップアップで警告があるときは、警告を大きく出し、やめる側を青・上書きする側を赤にする |
| ADR-0316 | 2026-10-08 | 警告があるセーブの確認では、やめる側をクラウドの色（青緑）・文字は黒にし、見出しも警告の内容に変える |
| ADR-0333 | 2026-10-10 | AutoPrestige は未確定の変更がある間 Apply を点滅させ、Current を反転表示で一番目立たせる |
