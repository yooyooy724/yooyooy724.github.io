**原則**: 乱数の偏りは合計や頻度を変えずに付け、見せない。当たりの段は開ける前に予告しない。

## なぜ

- 当たりの段を事前に知らせない方が、断続的な報酬として効く（ADR-0172）
- 全員が同じ一撃でそろって同じだけ押されると単調に見える（ADR-0328）
- 「範囲の限定ではなく確率で」（ユーザー指定、ADR-0178）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| ジオードは開く前の見た目を段によらず全部同じにし、開けたときの音程だけ段ごとに上げる | Idle-MInertia | ADR-0172 |
| Item Forge のドロップは周回ごとに最大 ±3.5% の偏りを付け、種類の中で釣り合わせて合計は変えない。偏りは見せない | Idle-MInertia | ADR-0335 |
| 運は稀な段を底上げし、ありふれた段から引く。伏せ札が出る頻度は変えない | Idle-MInertia | ADR-0247 |
| 通常装備 3 種の出現頻度は同じにする | Idle-MInertia | ADR-0347 |
| Spell はシード固定・重複なし・レアリティ重み付きで抽選する | Idle-MInertia | ADR-0043 |
| 見た目の揺らぎは一様乱数（ノックバック 0.8〜1.2 倍）で付ける | Idle-MInertia | ADR-0328 |
| 根の向きは範囲で縛らず、確率で真下に寄せる | Rootflux | ADR-0178 |
| 隠し実績は解除するまで名前と条件を伏せる | Idle-MInertia | ADR-0300 |

## 境界

- 釣りの成果と試練中には偏りをかけない（ADR-0335）
- 通常装備とエンチャントの 80:20 は動かさない（ADR-0335）

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0043 | 2026-05-15 | ローグライク要素として、Slay the Spire の Relic 風の「Spell」をシード固定の重み付き抽選で配る |
| ADR-0172 | 2026-09-26 | ジオードは開く前の見た目を全部同じにし、当たりを予告しない |
| ADR-0178 | 2026-09-28 | 根の伸びる向きは Prestige ごとに変え、コアからの根は範囲で縛らず確率で真下に寄せる |
| ADR-0247 | 2026-10-05 | 運は5段階にし、ジオードだけでなく釣り箱にも効かせる |
| ADR-0300 | 2026-10-08 | Steam 実績は 30 件で確定し、隠し実績を 2 件置く |
| ADR-0328 | 2026-10-10 | Area4 のノックバックの強さは 0.8〜1.2 倍（幅 40%）の乱数にし、止まる時間と押される距離の両方に掛ける |
| ADR-0335 | 2026-10-10 | Item Forge のドロップは Prestige の周回ごとに最大 ±3.5% の偏りを持つ |
| ADR-0347 | 2026-10-10 | 通常装備 3 種（マトック・ピッケル・ハンマー）の出現頻度を同じにする |
