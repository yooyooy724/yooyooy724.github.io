**原則**: 不正対策は、不正が他の遊び手や課金通貨に及ぶ場所だけを塞ぐ。正直な遊び手の体験を縛らず、課金通貨に触れない穴は許容する。

## なぜ

- 「重要なのはチーターを候補から外すことに限る」（ユーザー発言、ADR-0336）
- 「OfflineBonus は直接課金通貨を獲得するものではないから、C（サーバー判定）を採用しないのはまともな方法」（ユーザー発言、ADR-0413）
- 改竄したスコアでランキングが壊れるのを防ぐ（ADR-0011）
- 通貨を復元に含めると二重付与（ダイヤ増殖）の穴になる（ADR-0088）
- 放置ゲーの「機内モードでも報酬が出る」体験を崩さない（ADR-0413）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| メモリ改竄を検知したプレイヤーはランキングに参加できなくする | Idle-Sphere | ADR-0011 |
| Companion の候補は上限で絞ってチーターだけを外し、低レベルの人の恩恵は残す | Idle-MInertia | ADR-0336 |
| 実績の閾値は実機の記録からチーターの外れ値を除いて決める | Idle-MInertia | ADR-0301 |
| 捏造ビルド対策・通報・共有停止を入れる | Idle-MInertia | ADR-0048 |
| 課金の復元は広告除去などの権利だけ戻して通貨には触れず、「失敗」と「購入なし」を画面で区別する | Idle-MInertia | ADR-0088 |
| 課金したダイヤが古いクラウドセーブで巻き戻らないよう、ロード前に警告する。判定は同じ台帳同士で比べる | Idle-MInertia | ADR-0102 |
| どのボタンにも繋がっていない手動バックアップの経路は持たない（平文からの改ざん経路を残さない） | Idle-MInertia | ADR-0309 |
| 課金通貨に直結しない穴（時計を未来へ跳ばす）はサーバー判定を入れず許容し、記録を過去へ戻さないことだけ守る | Idle-MInertia | ADR-0413 |

## 境界

- 「到達レベル +3」の相対上限（ADR-0337）は低レベル帯を縛るので撤回した（ADR-0336）
- maxLevel はサーバーでなくクライアントが書く。大きい値の偽装は本人が見えなくなるだけ（ADR-0336）
- 残る穴は「機内モードで時計を未来へ跳ばす」手口（1 回 7 日分・代償は正規報酬の喪失）で、これは許容する（ADR-0413）
- セーブデータの改ざん対策（暗号化・クラウドの衝突ガード）の実装は開発方針「端末を信じない」の範囲

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0011 | 2024-11-24 | オンラインランキングを入れ、メモリ改竄を検知したプレイヤーは参加できなくする |
| ADR-0048 | 2026-06-09 | Nether に、他プレイヤーの装備ビルドを借りて一緒に潜る非同期の協力（コンパニオン）を入れる |
| ADR-0088 | 2026-07-27 | 課金の復元は広告除去などの権利だけを戻して通貨には触れず、「失敗」と「購入なし」を画面で区別する |
| ADR-0102 | 2026-08-03 | 課金したダイヤが古いクラウドセーブで巻き戻らないよう、ロード前に警告する |
| ADR-0301 | 2026-10-08 | Steam 実績はオフラインで解除できないものも入れ、閾値は外れ値を除いた実データで決める |
| ADR-0309 | 2026-10-08 | 手動バックアップ（manual_backup）の機能は持たない |
| ADR-0336 | 2026-10-10 | コンパニオンの候補の上限は「30 と自分の到達レベルの大きいほう」。+3 の相対上限はやめる |
| ADR-0413 | 2026-10-16 | オフライン報酬の時刻は、サーバー時刻を優先し、記録を過去へは戻さない |
