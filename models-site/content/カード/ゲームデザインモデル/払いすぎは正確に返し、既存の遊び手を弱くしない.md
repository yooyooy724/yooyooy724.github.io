**原則**: 値下げや仕様変更で遊び手が損をしたら、一律ではなく各自に正確に返す。値上げや段階の変更をしても、既存の遊び手が持っている効果・通貨・設定は減らさない。

## なぜ

- 一律にすると多く買った人ほど損をする（ADR-0177）
- 既存の効果を補正する案は「デメリットが大きすぎる」、旧枠と新枠を掛ける案は「既存プレイヤーが強くなりすぎる」（ユーザー判断、ADR-0397）
- 通貨を復元に含めると二重付与の穴になり、失敗を「購入なし」と出すと課金済みの人に誤って伝える（ADR-0088）
- 「ずれても再起動で修正されますか？」（ユーザー発言、ADR-0121）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 価格を下げたら、各プレイヤーの払いすぎた額ちょうどを返す | Idle-MInertia | ADR-0177 |
| 値上げしても、持っている効果の % は補正せず、手持ちの通貨もそのまま残す | Idle-MInertia | ADR-0397, ADR-0398 |
| 所持 Spell は保存値として信じず、起動時に受領記録から作り直し、ずれを自動で直す | Idle-MInertia | ADR-0121 |
| 課金の復元は権利（広告除去など）だけ戻して通貨には触れず、「失敗」と「購入なし」を画面で区別する | Idle-MInertia | ADR-0088 |
| 設定の段階を変えるときは、旧キーの値を同じ音量の段へ一度だけ移し、既存の遊び手の音量を変えない | Idle-MInertia | ADR-0327 |
| 一般公開で消すのはテスト期の進捗だけ。本番の進行は消さない | Idle-MInertia | ADR-0128 |

## 境界

- 返金を各自ちょうどにした判断は grill の回答で、AI の推奨を採った可能性がある（ADR-0177）
- 記録だけ消すと起動時の自己修復と噛み合わないので、所持 Spell も一緒に消す（ADR-0128）

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0088 | 2026-07-27 | 課金の復元は広告除去などの権利だけを戻して通貨には触れず、「失敗」と「購入なし」を画面で区別する |
| ADR-0121 | 2026-08-16 | 所持Spellは起動のたびに「現行マスタでの受領済み報酬」と抽選分から作り直し、ずれを自動で直す |
| ADR-0128 | 2026-08-24 | v0.9 で Area3 を一般公開し、テスター期間に積まれた試練の進捗だけは一度だけ消す |
| ADR-0177 | 2026-09-28 | 工房レベルのSoul価格を下げたとき、払いすぎた分を一律ではなく各プレイヤーに正確に返す |
| ADR-0327 | 2026-10-09 | 音量の段階は 0.04 を基準（既定）にして約 2 倍刻みの 9 段にし、World と UI の保存キーを分ける |
| ADR-0397 | 2026-10-14 | Bazaar は値段30倍・ボトルの効果12倍にし、既存の効果は削らない |
| ADR-0398 | 2026-10-14 | NetherCream の値段は「何日分の稼ぎで買えるか」で決め、倍率を NetherCreamMaster に置く |
