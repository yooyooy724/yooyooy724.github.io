**原則**: 一度作った要素でも遊びの芯から外れていれば削って単純にする。画面は独自のデザインを作らず既存の画面に揃え、版（モバイル / Steam）や向き（縦 / 横）が違っても遊びは同じにする。

## なぜ

- 「デザインが他のコンテンツと異なりすぎている。ほかのコンテンツを参考にデザインを一新」（ユーザー発言、ADR-0163）
- 演出の乏しさを補う表示を足すより、演出そのものを洗練させる（ADR-0134）
- 「基本的に Mobile と Steam では同じ挙動を想定しています」（ユーザー発言、ADR-0197）
- 同じ「順に受け取る報酬」なのに画面ごとに読み方が違うと見にくい（ADR-0219）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 釣りは耐久値・修繕・魚バフ・Metal Box を捨て、報酬を Loot 一本にする | Idle-MInertia | ADR-0156 |
| 演出の乏しさを補うためのポップアップは消し、ブロックを本物の 3D Cube にして演出を洗練させる | Idle-MInertia | ADR-0134 |
| 統計画面は独自デザインをやめ、既存画面（試練画面）の部品で作り直す。図は使わずモノクロにする | Idle-MInertia | ADR-0163 |
| 同じ種類の画面（マイレージとデイリーボーナス）は同じ格子＋受け取るボタン 1 つの形にする | 全体 | ADR-0219 |
| 同じ設定を編集する 2 つの画面（Relic と装備画面の自動化）は同じ見た目・同じ行の形にする | Idle-MInertia | ADR-0356 |
| 本線（モバイル）で UI を変えたら横長版にも必ず反映し、縦画面の窓は横長の窓をそのまま写す | Idle-MInertia | ADR-0185, ADR-0285 |
| Steam とモバイルは基本同じ挙動にし、違いは導線ごとに「モバイル / Steam 未所有 / Steam 所有」の表で 1 件ずつ決める | Idle-MInertia | ADR-0197 |
| 無料の受け取り（Supply）の回数と量はモバイルと Steam で共通にし、量は必ず線形に増やす | Idle-MInertia | ADR-0199 |
| 新しい見た目（Bazaar の自販機）が馴染まなければ以前の見た目に戻す | Idle-MInertia | ADR-0357 |

## 境界

- Automation のターミナル調と縦画面の窓は残した（ADR-0357）
- Steam だけ違う導線はある（飛ぶプレゼントは Steam では毎日回復、モバイルは生涯 3 回。ADR-0198）
- 統計画面に「ユニークな」独自デザインを試した判断は失敗として撤回した（ADR-0163）

## 根拠となった決定

| No. | 日付 | 決定 |

| ADR-0134 | 2026-08-26 | 盤面クリアの演出は擬似的な側面表現をやめ、ブロックを本物の3D Cubeで作り直す |

| ADR-0163 | 2026-09-21 | 統計画面は「ユニークな」独自デザインを試して失敗し、既存画面の部品に揃えて作り直す |
| ADR-0185 | 2026-10-01 | 本線（モバイル）でUIを変えたら、横長用のUXML（_H）にも必ず反映し、そのルールを明記する |
| ADR-0197 | 2026-10-02 | Steam とモバイルは基本同じ挙動にし、違いは導線ごとに個別に決める |
| ADR-0199 | 2026-10-02 | Supply は無料 2 回 + 広告または DLC で 3 回の計 5 回にし、量は線形に増やす |
| ADR-0219 | 2026-10-04 | マイレージ画面は行の一覧をやめ、デイリーボーナスと同じ 4 列の格子＋受け取るボタン 1 つにする |

| ADR-0356 | 2026-10-11 | Relic と装備画面の Automation 設定を同じ見た目・同じ行の形に揃える |
| ADR-0357 | 2026-10-11 | Relic の Bazaar は自販機の見た目をやめ、以前の露店の見た目に戻す |
