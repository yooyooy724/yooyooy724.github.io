**原則**: 知らせは画面を遮って押し付けず、一覧・赤い点・ヒント・ヘルプなど遊び手が自分で引ける場所に置く。教える量は減らし、読むかどうかは遊び手が選ぶ。

## なぜ

- あちこちに鍵が出ると Pay to Win に見え、ストアページの印象を損なう（ADR-0192）
- 「Hint は Tutorial との違いとして、一覧性を重視する」（ユーザー発言、ADR-0344）
- ポップアップは画面二重化の不具合を繰り返したので、仕組みごと減らした（ADR-0147）
- チュートリアルの説明ポップアップは一度確認すると二度と開けない（ADR-0259）

## 規則

| 規則 | 範囲 | 根拠 |
| --- | --- | --- |
| 初めて手に入れた通貨・アイテムのポップアップはやめ、図鑑（INDEX）のグリッドと赤ポチで知らせる。通知ポップアップはコンテンツ解禁とマップ解禁だけ | Idle-MInertia | ADR-0084 |
| 購入は確認なしでその場で解禁し、ポップアップの仕組みごと減らす | Idle-Sphere | ADR-0147 |
| DLC 未所有のボタンは鍵つきで見せずに隠し、DLC は売り場にだけ並べる | Idle-MInertia | ADR-0192 |
| ヒントは見え方がまとまった「区画」単位で設計し、各画面のボタンとオプションの一覧の 2 経路で出す | Idle-MInertia | ADR-0259, ADR-0346 |
| ヒントはページ送りせず、1 枚のパネルに全部を並べて ScrollView で見せる | Idle-MInertia | ADR-0344 |
| ヒントボタンを隠すかは OK でなく、OK の上のトグルで遊び手が選ぶ | Idle-MInertia | ADR-0345 |
| Help はオプションから開き、解禁前のコンテンツも項目を出す | Idle-MInertia | ADR-0228 |
| チュートリアルは「ピッケルを押す」を外し、装備するところから始める | Idle-MInertia | ADR-0321 |
| 設定（Prestige 自動化）はポップアップでなく自動化タブに常に出す | Idle-MInertia | ADR-0250 |

## 境界

- ヒントで未解放の機能は出さない（ADR-0346）。Help では解禁前の項目も出す（ADR-0228）
- 「OK を押したらヒントボタンを消す」（ADR-0343）は同日に「トグルで選ぶ」へ改めた（ADR-0345）
- ポップアップ廃止（ADR-0084）の理由は明言されていない

## 根拠となった決定

| No. | 日付 | 決定 |
| --- | --- | --- |
| ADR-0084 | 2026-07-24 | 初めて手に入れた通貨やアイテムのポップアップをやめ、図鑑（INDEX）のグリッドと赤ポチで知らせる |
| ADR-0147 | 2026-09-07 | DLC とデフォルト以外の色・エフェクトはゲーム内通貨 Arc で売り、色 250・Comic 750 とし、購入は確認なしでその場で解禁する |
| ADR-0192 | 2026-10-02 | DLC 未所有のとき対象のボタンは隠し、所有で出るボタンは専用の見た目にする |
| ADR-0228 | 2026-10-05 | Help 画面は Option 画面から開き、コンテンツごとの項目ボタンで遊び方を見せる |
| ADR-0250 | 2026-10-06 | Prestige 自動化の設定はポップアップをやめて自動化タブに常に出し、開閉は端末に保存する |
| ADR-0259 | 2026-10-06 | ヒントは「区画」単位で設計し、計画はノートサイトの HintSite に置く |
| ADR-0321 | 2026-10-09 | チュートリアルは「ピッケルを押す」を外し、装備するところから始める |
| ADR-0344 | 2026-10-10 | ヒントはページ送りせず、1枚のパネルに全部を並べて ScrollView でスクロールさせる |
| ADR-0345 | 2026-10-10 | ヒントボタンを隠すのは OK ではなく、OK の上のトグルで選ぶ |
| ADR-0346 | 2026-10-10 | 画面ごとのヒントを、ヒントボタンとオプションのヒント一覧の2経路で出す |
