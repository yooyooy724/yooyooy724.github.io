Idle MInertia の届け方と売り方。全体の原則（[[全体/ビジネス]]）を、この作品でどう具体化しているかをまとめた提案。

## 出す場所

| 場所 | 決まっていること |
| --- | --- |
| モバイル（iOS・Android） | 本線。Apple サインインは iOS だけに出し、同期できる範囲を画面で明示する |
| Steam | 期限を切らず、全部入りで Windows と Mac に同時に出す。基本無料 |
| Web（WebGL） | ゲームサイト向けに試作した |

## 収益の導線

| 導線 | モバイル | Steam |
| --- | --- | --- |
| 広告報酬 | 空飛ぶ宝箱は最初の10回を広告なしで受け取れる | 広告はやめ、DLC に置き換える |
| Diamond | 販売する | 販売しない |
| 買い切り | Nether の挑戦回数を増やす | DLC。商品名はモバイルに揃える |
| Diamond の使い道 | Nether Companion の引き直し（回数制） | — |

## 遊び手への頼み方

- 評価のお願いは、Area2 に到達した人にだけ出す。
- 開発中のエリアは、テスター判定つきで本番に入れて先に遊んでもらう。
  - 告知では「消える進捗」と「残る報酬」を先に約束する。
  - パッチノートに Testing Feature の節を設ける。

## 数字の見方

- 国ごとの購入意欲は、購入者数 ÷ ダウンロード数で比べる。
- 販売分析のダッシュボードは、認証の裏に置く。

## 販促

- 販促は発信（X）とは目的を分け、まず効果を測れる状態を作る。
- ストアのキーワードは重要な語に絞り、旧名でも検索に出るようにする。
- 海外コミュニティへの投稿は、AI 利用の開示と投稿頻度の規則に従う。
