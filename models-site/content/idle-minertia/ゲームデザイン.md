Idle MInertia の遊びの構成。全体の原則（[[全体/ゲームデザイン]]）を、この作品の各コンテンツでどう具体化しているかをまとめた提案。

## コンテンツの構成

| コンテンツ | 役割 | 決まっていること |
| --- | --- | --- |
| Cave（本編） | 掘り進める放置の芯 | エリアは配列で持ち、後から増やせる。進行の壁は階層の解放の瞬間に置き、解放後は楽にする |
| Battle | 本編と並ぶもう1つの成長軸 | ECS 型のタワーディフェンス |
| Nether | 決まった周期で開く期間イベント | 装備を送り込んで挑む。挑戦回数は買い切りで増やせる |
| Nether Companion | 腕前に関係なく参加できる協力 | 他プレイヤーの装備を借りる非同期協力。候補は Nether の期間ごとに固定し、引き直しは回数制 |
| 祠の試練（Challenge） | 本編の味変 | 本編 Cave に縛りを加えて作る。共通の4段 Tier で倍率の無効化を重ね、報酬は Tier ごとの Spell |
| Spell | 試練の報酬 | Slay the Spire の Relic 風。シード固定で抽選し、効果は純粋なプラスだけ |
| 露店（Relic） | 恒久的な強化 | 効果は Battle と掛け算。支払いは NetherCream だけ |
| 釣り | 低確率・高効果の味変 | マイナスのない作りにし、報酬は Loot の一本に絞る |
| ジオード | 断続的な報酬 | 開ける前に当たりを予告しない |
| マスタープレステージ | 長期の目標 | 目的は Forge Level を伸ばし続けることに絞る。リセットで残すものを Root ごとに明示する |

## 通貨

| 通貨 | 決まっていること |
| --- | --- |
| Diamond | 供給を止めないよう、クリア済みミッションを再び出す。釣り合いはコストではなく入手量で取る |
| NetherCream | 露店の支払いにだけ使う |
| 新しい希少通貨 | プレステージの周回で稼げない形にする |

## 自動化

- 自動化は Relic の購入で解禁し、コストは「何日分の進行か」で決める。
- 自動化の設定は実体を1つにし、どの画面から触っても同じものを変える。
- 自動マージは、1回でできるものをまとめて行う。
- 変換の行き先指定はいったんやめ、選べる権利を Spell の報酬として返す。

## 見せ方と知らせ方

| 対象 | 決まっていること |
| --- | --- |
| 獲得の通知 | 獲得のたびのポップアップをやめ、図鑑の Index と赤い点で知らせる |
| レア度 | 色相ではなく点の数と明るさで伝える。開放音は段ごとに音程を上げる |
| 統計画面 | 独自デザインをやめ、既存の画面に揃える |
| 宝石 | 最後のバイオームの宝石は、既存と重ならないよう色と形の並びを見て決める |

## 公平さ

- 値下げしたら、払いすぎた分を各自に正確に返す。
- 難しいミッションは、出ることではなく居座り続けることを直す。
- 放置中のオフライン報酬は、実測の速さだけに頼らず期待値で下限を保証する。
