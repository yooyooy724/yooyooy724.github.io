このサイトの編集規則。人は [編集画面](/admin/) から編集する。Claude は提案だけを書く。

## 編集画面へのログイン

1. [編集画面](/admin/) を開く
2. 「Sign In with Token」を選ぶ
3. GitHub の Personal Access Token（このリポジトリの Contents: Read and write 権限）を貼る

- 保存すると GitHub に直接コミットされ、数分後にこのサイトへ反映される。

## ページの欄

| 欄 | 値 | 意味 |
| --- | --- | --- |
| `type` | 地図 / 範囲 / モデル / リスク | ページの種類 |
| `kind` | 全体 / グループ / プロジェクト | 範囲ページだけ |
| `groups` | グループの範囲ページ名 | プロジェクトの範囲ページだけ。属するグループ |
| `category` | 世界観 / ゲームデザイン / 開発方針 / ビジネス | モデルページだけ |
| `status` | 提案 / 確定 | 確定にするのは人だけ |

## 置き場所

```
content/
├── index.md              このサイトの地図
├── 全体/index.md         範囲ページ
├── 全体/<カテゴリ>.md    モデルページ
├── <プロジェクト>/index.md
├── <プロジェクト>/<カテゴリ>.md
├── <グループ>/index.md   2つ以上のプロジェクトで必要になったら作る
└── リスク.md             全範囲のリスクを1ページに並べる
```

- ファイル名が範囲間で重なるので、リンクは `[[全体/開発方針]]` のようにフォルダ付きで書く。

## Claude の提案

| 状況 | 書き方 |
| --- | --- |
| 新しいページを作る | ページの `status: 提案` |
| 確定済みのページに足す | 本文に提案の囲みを置く（下の例） |

```
> [!question] 提案（Claude, 2026-10-01）
> 提案の本文
```

- 人が採用したら、囲みを外して本文に混ぜる。不採用なら囲みごと消す。
