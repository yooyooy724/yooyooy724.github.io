このサイトの編集規則。人は [編集画面](/admin/) から編集する。Claude は提案だけを書く。

## 編集画面へのログイン

1. [編集画面](/admin/) を開く
2. 「Sign In with Token」を選ぶ
3. GitHub の Fine-grained Personal Access Token（このリポジトリだけ・Contents: Read and write）を貼る

- 保存すると GitHub に直接コミットされ、数分後にこのサイトへ反映される。

## カード

モデルは**1つの原則＝1枚のカード**として書く。

| 欄 | 値 | 意味 |
| --- | --- | --- |
| `title` | 原則を短く言い切った題 | 例: 三段で売る |
| `category` | 世界観モデル / ゲームデザインモデル / 開発方針 / ビジネスモデル | 置くカテゴリ |
| `tags` | 全体 / Idle-MInertia / グループ名 | 範囲の札。複数付けてよい |
| `status` | 提案 / 確定 | 確定にするのは人だけ |
| `description` | 1文 | カード一覧に出る要約 |

- 本文には、中身（1〜3文）と「根拠となった決定」を書く。

## 置き場所

```
content/
├── index.md                    このサイトの地図
├── 世界観モデル.base など       カテゴリのページ（カード一覧。タブで範囲を切り替える）
├── カード/<カテゴリ>/<題>.md     カード
├── リスク.md                   全範囲のリスクを1ページに並べる
└── 運用.md                     このページ
```

- カテゴリのページは `.base`（カードを集めて一覧にする定義）。カードを足すだけで一覧に出る。
- フォルダ名に英字の大文字を使わない。Windows で大文字・小文字違いのパスが衝突する。

## リスクの書き方

- [[リスク]] は遭遇者（遊び手／開発者）ごとの表にする。1行1件
- 列は「リスク／範囲／いつ起きるか／避け方／出典」。範囲は「全体」かプロジェクトの表示名

## Claude の提案

| 状況 | 書き方 |
| --- | --- |
| 新しいカードを作る | カードの `status: 提案` |
| 確定済みのカードに足す | 本文に提案の囲みを置く（下の例） |

```
> [!question] 提案（Claude, 2026-10-01）
> 提案の本文
```

- 人が採用したら、囲みを外して本文に混ぜる。不採用なら囲みごと消す。
