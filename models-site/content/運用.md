このサイトの編集規則。人は [編集画面](/admin/) から編集する。Claude は提案だけを書く。

## 編集画面へのログイン

1. [編集画面](/admin/) を開く
2. 「Sign In with Token」を選ぶ
3. GitHub の Fine-grained Personal Access Token（このリポジトリだけ・Contents: Read and write）を貼る

- 保存すると GitHub に直接コミットされ、数分後にこのサイトへ反映される。

## カード

モデルは**1つの原則＝1枚のカード**として書く。原則は少数に絞り、個別の決定は原則の下の「規則」の行に置く（2段構造）。

| 欄 | 値 | 意味 |
| --- | --- | --- |
| `title` | 原則を短く言い切った題 | 例: 事故は構造で防ぐ |
| `category` | 世界観モデル / ゲームデザインモデル / 開発方針 / ビジネスモデル | 置くカテゴリ |
| `tags` | 先頭に範囲（全体 / Idle-MInertia / グループ名）、続けてテーマ（下の語彙） | 例: `[全体, 報酬, 公平さ]` |
| `status` | 提案 / 確定 | 確定にするのは人だけ |
| `description` | 1文 | カード一覧に出る要約 |
| `adrs` | ADR 番号の配列（昇順） | 例: `[12, 45, 301]`。根拠の表と同じ番号 |

### 本文の節

| 節 | 書くこと |
| --- | --- |
| **原則** | 1〜2文の言い切り。理由は書かない |
| なぜ | 背後にある価値・狙い。本人の発言が根拠ならその趣旨 |
| 規則 | 原則を具体化した決まりの表（規則／範囲／根拠）。プロジェクトの事実はここに置く |
| 境界 | 当てはまらない場合、撤回した判断、未決のこと |
| 根拠となった決定 | ADR の表（No.／日付／決定）。番号は保管庫の `ADR一覧` の通し番号 `ADR-0001 …` |

### 原則にする基準

- 根拠の ADR が **2件以上**ある。1件のときは、時間的般化か独特度が「高」のときだけ原則にし、境界に「根拠は1件」と書く
- 1枚 = 1つの主張。主張が2つなら分け、同じ主張が2枚なら1枚にまとめる
- 撤回・反転した決定は捨てず、境界に前後の決定を並べる
- 範囲は、根拠が2つ以上のプロジェクトにまたがるか、明らかに全プロジェクトに当てはまるなら `全体`
- 目安はカテゴリごとに 8〜15 枚。超えたら統合を考える

### テーマタグの語彙

| 分野 | タグ |
| --- | --- |
| 世界観 | 物語・世界の法則・言葉と表現 |
| ゲームデザイン | 報酬・通貨・進行・公平さ・通知と画面・協力 |
| 開発 | 設計構造・セーブ・堅牢性・性能・品質管理・作業管理・エージェントとの分担・自動化 |
| ビジネス | 販路・収益化・販促・数字の見方・テスト公開 |
| 横断 | 遊び手との関係 |

- 語彙にないタグを足すときは、この表にも足す（同じ意味のタグを2つ作らないため）。

## 編集ボタン

- 各ページの右下にある「✎ このページを編集」を押すと、編集画面でそのページが開く。

## 置き場所

```
content/
├── index.md                    このサイトの地図
├── 世界観モデル.base など       カテゴリのページ（カード一覧。タブで範囲を切り替える）
├── カード/<カテゴリ>/<題>.md     カード
├── リスク.md                   全範囲のリスクを1ページに並べる
└── 運用.md                     このページ
```

- カテゴリのページは `.base`（カードを集めて一覧にする定義）。カードを足すだけで一覧に出る。
- フォルダ名・ファイル名に英字の大文字を使わない（題の大文字は title 欄に書く）。大文字・小文字だけ違うページが2つ生成され、Windows で衝突する。

## リスクの書き方

- [[リスク]] は遭遇者（遊び手／開発者）ごとの表にする。1行1件
- 列は「リスク／範囲／いつ起きるか／避け方／出典」。範囲は「全体」かプロジェクトの表示名

## Claude の提案

| 状況 | 書き方 |
| --- | --- |
| 新しいカードを作る | カードの `status: 提案` |
| 確定済みのカードに足す | 本文に提案の囲みを置く（下の例） |

```
> [!question] 提案（Claude, 2026-10-01）
> 提案の本文
```

- 人が採用したら、囲みを外して本文に混ぜる。不採用なら囲みごと消す。
