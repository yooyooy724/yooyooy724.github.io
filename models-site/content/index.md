YayuProjects の開発の拠り所となる**抽象的デザインモデル**と**リスク**をまとめたサイト。YayuProjects 開発サイクルの「解釈」で育て、「翻訳」「適応」で開発に戻す。

## カテゴリ

モデルは1つずつカードになっている。カテゴリを開くと、そのカテゴリのカードが一覧できる。

| カテゴリ | 中身 |
| --- | --- |
| [[世界観モデル.base\|世界観モデル]] | 作品世界の前提・象徴・トーン |
| [[ゲームデザインモデル.base\|ゲームデザインモデル]] | 遊びの核、報酬・成長・公平さの設計 |
| [[開発方針.base\|開発方針]] | 作り方・判断の仕方・AI との分担・自動化 |
| [[ビジネスモデル.base\|ビジネスモデル]] | 出す場所、売り方、数字の見方 |

## 範囲

各カードには、当てはまる範囲の札が付いている。カテゴリのページのタブで、範囲ごとに絞り込める。

| 札 | 意味 |
| --- | --- |
| 全体 | 今後のプロジェクトも含む、すべての開発プロジェクトに当てはまる |
| Idle-MInertia | Idle MInertia だけに当てはまる |

- グループ（例: 放置ゲーム）は、2つ以上のプロジェクトで同じ性質が必要になったときに札として作る。

## タグ

各カードには、範囲の札とは別に**テーマのタグ**（報酬・セーブ・収益化 など）が付いている。

- [[タグ表]] — タグ × カテゴリの枚数の表。枚数の少ないマスが、まだ考えが足りていないところの目安になる
- [タグ一覧](tags/) — タグごとに、付いているカードを眺められる
- カードの上部のタグを押すと、同じタグの付いたカード（関連するカード）に飛べる

## リスク

- [[リスク]] — 遊び手・開発者が遭遇しうる、事前に避けるべき事項の一覧
